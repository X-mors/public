# موقع بوت التداول الذكي

موقع احترافي لبيع بوت التداول الخاص بك مع واجهة عربية حديثة وجذابة.

## المميزات

- 🎨 تصميم حديث ومتجاوب
- 🌐 دعم كامل للغة العربية
- 📱 متوافق مع جميع الأجهزة
- ⚡ سريع ومحسن للأداء
- 🔒 آمن ومحمي
- 📊 إحصائيات وتقارير مفصلة

## التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - لكتابة كود آمن ومنظم
- **Tailwind CSS** - لتنسيق سريع وجميل
- **Lucide React** - أيقونات حديثة
- **Framer Motion** - حركات وتأثيرات

## التثبيت والتشغيل

### المتطلبات الأساسية

- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   git clone <repository-url>
   cd trading-bot-website
   ```

2. **تثبيت التبعيات**
   ```bash
   npm install
   ```

3. **تشغيل المشروع في وضع التطوير**
   ```bash
   npm start
   ```

4. **فتح المتصفح**
   انتقل إلى `http://localhost:3000`

### بناء المشروع للإنتاج

```bash
npm run build
```

## هيكل المشروع

```
src/
├── components/          # مكونات React
│   ├── Header.tsx     # رأس الصفحة
│   ├── Hero.tsx       # القسم الرئيسي
│   ├── Features.tsx   # المميزات
│   ├── Pricing.tsx    # الأسعار
│   ├── Testimonials.tsx # آراء العملاء
│   ├── Contact.tsx    # صفحة الاتصال
│   └── Footer.tsx     # تذييل الصفحة
├── App.tsx            # المكون الرئيسي
├── index.tsx          # نقطة البداية
└── index.css          # الأنماط الرئيسية
```

## التخصيص

### تغيير الألوان

يمكنك تخصيص الألوان من خلال تعديل ملف `tailwind.config.js`:

```javascript
colors: {
  primary: {
    50: '#eff6ff',
    100: '#dbeafe',
    // ... المزيد من الألوان
  }
}
```

### تغيير المحتوى

يمكنك تعديل النصوص والمحتوى من خلال تعديل الملفات في مجلد `components/`.

### إضافة صفحات جديدة

1. أنشئ مكون جديد في مجلد `components/`
2. أضف المكون إلى `App.tsx`
3. أضف رابط التنقل في `Header.tsx`
